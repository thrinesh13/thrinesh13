## Featured projects

These independent projects show how I frame a business question, validate data, choose an analytical approach, and communicate the result.

### 01 · Operating Room Scheduling Reliability & Cost Exposure

**Where should an operations team investigate unpredictable procedure durations?**

Built a Microsoft Fabric pipeline and Power BI semantic model covering **48,118 surgical cases across 418 procedures**. Measured a **54.1-minute mean absolute difference** from historical procedure benchmarks and estimated **$15.8M–$27.1M in annual gross time-cost exposure** under documented planning assumptions.

The benchmark is a historical procedure median, rather than the booked time slot. The financial figures are modeled exposure, not realized losses or savings.

**Tools:** Microsoft Fabric · PySpark · SQL · Power BI · DAX

[Interactive dashboard](https://thrinesh13.github.io/OR-Scheduling-Reliability-Analytics/) · [Code & methodology](https://github.com/thrinesh13/OR-Scheduling-Reliability-Analytics) · [Data quality approach](https://github.com/thrinesh13/OR-Scheduling-Reliability-Analytics/blob/main/docs/DATA_QUALITY.md)

### 02 · Medicare Claims Processing Analytics

**When does automating claims approval actually save money?**

Compared manual review, basic checks, and checks-plus-score policies on **6,627 synthetic submissions**. Adding a score prevented **100 incorrect approvals compared with basic checks**. The combined policy produced **$73,194 in modeled net savings versus manual review**, after processing and incorrect-approval costs under the default assumptions.

The analysis includes cost sensitivity and review-workload trade-offs. Results are project scenarios, not realized payer outcomes.

**Tools:** PostgreSQL · SQL · Python · Pandas · Jupyter

[Project overview](https://github.com/thrinesh13/Medicare-Claims-Processing-Analytics) · [Decision methodology](https://github.com/thrinesh13/Medicare-Claims-Processing-Analytics/blob/main/methodology.md) · [SQL implementation](https://github.com/thrinesh13/Medicare-Claims-Processing-Analytics/tree/main/sql)
